# Currency Exchange Rate Analyzer

A Python project that retrieves historical currency exchange rates from a public API and analyses them using Pandas.

## Features

- Retrieves exchange rates from the Frankfurter API.
- Analyses EUR against USD, GBP and JPY.
- Calculates average exchange rates.
- Finds maximum and minimum rates.
- Calculates percentage changes.
- Exports the results to a CSV file.

## Technologies

- Python
- Requests
- Pandas
- REST API
- JSON
- CSV

## API

Frankfurter API:
https://www.frankfurter.app/

No API key required.

## Installation

Install the required libraries:

pip install -r requirements.txt

## How to Run

python currency_analyzer.py

## Output

The program displays exchange rate statistics and creates an exchange_rates.csv file.
